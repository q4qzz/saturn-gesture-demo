# 第三方依赖说明

本项目依赖 Three.js 和 MediaPipe Hands，体积约 25 MB，未提交到仓库。
按下述步骤下载并放到 `vendor/` 目录即可运行。

---

## 一、Three.js

**需要文件**：`vendor/three.module.js`

### 方式 A：从 CDN 直接下载（推荐）

浏览器打开下面这个地址，另存为 `vendor/three.module.js`：

```
https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js
```

### 方式 B：用 npm 安装后复制

```bash
npm install three@0.160.0
# 然后把 node_modules/three/build/three.module.js 复制到 vendor/
```

> ⚠️ 版本说明：`index.html` 用的是 ES Module + importmap 写法，
> 需要 **r150 以上**的版本（更早的版本包结构不同）。

---

## 二、MediaPipe Hands

**需要目录**：`vendor/mediapipe/`

### 方式 A：从 npm 包下载（推荐）

```bash
npm install @mediapipe/hands
```

安装后，把 `node_modules/@mediapipe/hands/` 目录下**所有文件**复制到 `vendor/mediapipe/`。

该目录应包含这些文件：

```
vendor/mediapipe/
├── hands.js                                  # 主入口
├── hands.binarypb                            # 计算图定义
├── hands_solution_packed_assets.data         # 打包资源
├── hands_solution_packed_assets_loader.js    # 资源加载器
├── hands_solution_wasm_bin.js                # WASM 绑定（非 SIMD）
├── hands_solution_wasm_bin.wasm              # WASM 二进制（非 SIMD）
├── hands_solution_simd_wasm_bin.js           # WASM 绑定（SIMD 加速版）
├── hands_solution_simd_wasm_bin.wasm         # WASM 二进制（SIMD 加速版）
├── hand_landmark_full.tflite                 # 手部关键点模型（完整版，精度高）
└── hand_landmark_lite.tflite                 # 手部关键点模型（轻量版，速度快）
```

### 方式 B：从 jsdelivr 逐个下载

```
https://cdn.jsdelivr.net/npm/@mediapipe/hands/
```

浏览器打开后可以浏览全部文件并逐个保存。

---

## 三、验证依赖是否就位

依赖放好之后，`vendor/` 应该长这样：

```
vendor/
├── three.module.js          （约 1.2 MB）
└── mediapipe/
    ├── hands.js             （约 45 KB）
    ├── hands.binarypb
    ├── hand_landmark_full.tflite   （约 5.2 MB）
    ├── hand_landmark_lite.tflite   （约 2.0 MB）
    └── ... 其余文件
```

**快速检查**：

```bash
ls -lh vendor/three.module.js vendor/mediapipe/hands.js
```

两个文件都在，就说明基本就位了。

## 四、启动

```bash
# 在项目根目录
python -m http.server 8000
```

然后浏览器打开：

```
http://localhost:8000
```

### 为什么必须用 HTTP 服务器？

1. **ES Module 加载**：`<script type="module">` 在 `file://` 协议下会被浏览器的
   同源策略拦截，直接双击 HTML 会白屏。
2. **摄像头权限**：`getUserMedia` 只在 **HTTPS** 或 **localhost** 下可用。
   用 `localhost` 正好满足。

## 五、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 页面白屏，控制台报 `Failed to resolve module specifier "three"` | `vendor/three.module.js` 不存在 | 按第一节下载 |
| 页面正常但手势没反应，提示 `hands.js 未加载` | `vendor/mediapipe/` 缺文件 | 按第二节下载 |
| 手势面板显示 `摄像头：失败 (NotAllowedError)` | 摄像头权限被拒 | 用 `localhost` 访问，并在浏览器地址栏允许摄像头 |
| 只有黑色背景没有土星 | WebGL 被禁用 | 浏览器设置里启用硬件加速 |
